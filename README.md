# БДЖ Мобилно Приложение - Бекенд MVP (Фаза 1)

Този проект съдържа API сървъра и автоматичния инструмент (Scraper) за извличане на закъсненията от БДЖ в реално време.

## 🚀 Как да го стартирате локално на вашия компютър:

1. Инсталирайте **Node.js** (версия 18 или по-нова) и **Redis**.
2. Влезте в папка `backend` през терминала си и инсталирайте библиотеките:
   ```bash
   npm install
   ```
3. Стартирайте **API Сървъра** (който ще обслужва мобилното приложение):
   ```bash
   npm start
   ```
4. В нов терминал стартирайте **Скрипта за обновяване (Worker)**:
   ```bash
   npm run worker
   ```

##  Управление на сървъра в реална среда (Производство):
За да не спират скриптовете, когато затворите терминала, програмистите използват инструмента `PM2`:
* Старт на всичко: `pm2 start src/index.js --name bdz-api` и `pm2 start src/worker.js --name bdz-worker`
* Проверка на състоянието: `pm2 status`
* Преглед на логове (за грешки): `pm2 logs`
